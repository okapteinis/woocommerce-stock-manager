# WooCommerce Stock Manager

Stock Manager for WooCommerce - independent development fork.

## About This Repository

This is an independent fork of the WooCommerce Stock Manager plugin (version 3.4.0) maintained for custom development purposes.

**Original Plugin:** [Stock Manager for WooCommerce](https://wordpress.org/plugins/woocommerce-stock-manager/)
**Original Author:** StoreApps
**Original License:** GPLv2

## Description

Stock Manager is a powerful WooCommerce stock management plugin that allows you to manage product stock and their variations from one screen.

Edit and manage product stock status, quantity, prices, SKU, taxes, apply quick filters and view stock history, import and export stock data to CSV.

## Features

- **Table Editor** - Make edits to stock data using table cells and dropdown
- **Inline Edit** - Create, remove or update stock items
- **Stock and Price Management** - Edit SKU, product name, tax status, tax class, shipping class, price, sale price, weight, stock status, backorders, and stock quantity
- **Support for All Product Types** - Simple, variable, external/affiliate, grouped
- **Admin Columns** - Show/hide columns based on requirements
- **Pre-defined Search Filters** - Filter by product category, product type, and stock status
- **Product Stock History** - Track stock changes over time
- **Import/Export** - CSV import and export functionality
- **Product Thumbnails** - View product images in the dashboard
- **Variable Products** - Edit variations after clicking "Show variables"

## Version Information

- **Current Version:** 3.4.0
- **Requires WordPress:** 5.0.0+
- **Tested up to:** WordPress 6.8
- **Requires PHP:** 5.6+
- **WooCommerce Compatibility:** Latest versions

## Installation

1. Upload the plugin files to `/wp-content/plugins/woocommerce-stock-manager/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Access the Stock Manager dashboard from WooCommerce menu

## Development
